### Debloating Windows can sometimes feel like a tedious task. Not anymore

With these scripts designed to be used with PowerShell as administrator you can easily fine-tune Windows so it has less overall background processes, working local search without Bing and no Edge browser

Disable telemetry with one of the scripts depending which Windows you're running. General optimization script is designed alongside the scope of Microsoft's guidelines so it's highly universal. It still leaves actually useful aspects of the OS such as Wi-Fi, Bluetooth, printing, emoji board and other typical areas untouched
