# WinDebloat

Debloating Windows can sometimes feel like a tedious task. Not anymore.

WinDebloat is a small collection of PowerShell scripts for trimming common Windows background noise, reducing telemetry, restoring a cleaner local search experience without Bing results, and removing Microsoft Edge where the matching script supports it. The scripts are intended to be run from an elevated PowerShell session and are organized by scope so you can apply only the changes that match your Windows version and your setup goal.

The Winget Chrome install script installs Google Chrome through Windows Package Manager (`winget`) using the official package source instead of requiring a manual browser download. It is useful after removing Edge or when setting up a fresh Windows installation, because Chrome can be installed from PowerShell as part of the same repeatable setup flow. The script requires `winget`/App Installer to be available and may require administrator elevation depending on installer behavior.

## Quick summary of what each script does

| Script / role                | What it modifies                                                                                                                                                                                       | What it leaves alone                                                                                                     | Compatible Windows versions / editions                                                                                                                                                                                                            |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| General optimization script  | Applies broad Windows fine-tuning intended to reduce unnecessary background activity, keep local search usable without Bing web results, and remove or reduce Edge-related components where supported. | Keeps everyday OS functionality such as Wi-Fi, Bluetooth, printing, emoji panel, and normal desktop usage intact.        | Windows 10 and Windows 11 desktop editions: Home, Pro, Enterprise, and Education. Run as administrator.                                                                                                                                           |
| Windows 10 telemetry script  | Reduces Windows 10 diagnostic/telemetry behavior through supported settings, policies, services, and scheduled-task changes where available.                                                           | Does not remove core networking, update, security, driver, or device functionality.                                      | Windows 10 desktop editions: Home, Pro, Enterprise, and Education. Some policy-based settings may apply more completely on Pro/Enterprise/Education than Home.                                                                                    |
| Windows 11 telemetry script  | Reduces Windows 11 diagnostic/telemetry behavior using the Windows 11-specific set of supported settings, policies, services, and scheduled-task changes.                                              | Does not remove core networking, update, security, driver, or device functionality.                                      | Windows 11 desktop editions: Home, Pro, Enterprise, and Education. Some policy-based settings may apply more completely on Pro/Enterprise/Education than Home.                                                                                    |
| Winget Chrome install script | Uses Windows Package Manager to install Google Chrome from the `Google.Chrome` package, making browser installation scriptable after debloating or Edge removal.                                       | Does not debloat Windows, remove Edge, or change privacy settings; it only handles Chrome installation through `winget`. | Windows 10 version 1809/build 17763 or later, Windows 11, and Windows Server 2025 with Desktop Experience where `winget`/App Installer is available. Works across Home, Pro, Enterprise, and Education desktop editions when `winget` is present. |

## Notes

* Run PowerShell as administrator before applying system-level debloat or telemetry changes.
* Use the telemetry script that matches your Windows version instead of running both Windows 10 and Windows 11 variants.
* Review each script before running it so you understand exactly which settings will be changed on your machine.
